# 🍔 INJOY Burger — Static Restaurant Website

INJOY Burger is a modern and responsive static website built with **HTML**, **CSS**, and **JavaScript**. Designed for a fictional gourmet burger restaurant, it delivers an engaging user experience with smooth interactions and a clean UI.

## 🚀 Features

- 📱 Fully responsive layout
- 🎨 Stylish and modern UI design
- ⚡ Fast loading static website
- 📜 Smooth scrolling and interactive elements
- 💡 Easy to customize and maintain
